# 口袋 · Slint 美化预览

独立的 Rust + Slint 桌面预览，使用 winit 窗口后端和软件渲染，无 WebView。

## 运行

双击 `target/release/pocket-pet-slint.exe`。启动只显示小猫；悬停小猫速览待办，点击小猫打开完整记录面板。

- 单击小猫：展开统一口袋面板，再次点击收起；拖动小猫：移动位置。
- 待办徽标打开同一面板。顶部始终新增，下方直接查看待办；点击圆圈完成，点击正文在列表内展开阅读，再点击正文或“编辑”修改，不覆盖顶部草稿。
- 输入气泡自动聚焦，Ctrl+V 在光标位置粘贴文字，粘贴截图显示附件预览。
- Enter 或“收下”保存后保持面板展开，新记录直接进入列表；Shift+Enter 换行。输入法组词期间不拦截这些按键。
- Esc、× 或切换到其他窗口时收起并保留草稿；右上角“…”菜单提供收下剪贴板和退出。
- 空草稿保持紧凑，输入文字或粘贴图片后展开，“收下”按钮整合在输入区内。
- 点击图片缩略图，在同一气泡内放大查看；多图可前后切换，Esc 返回。预览最长边限制为 1200 像素。
- 新记录短暂淡入并高亮；操作提示自动淡出；没有已完成记录时隐藏已完成入口。
- **Ctrl+Alt+V**：全局快捷收下剪贴板，图片优先，其次文字/链接；不展开输入框、不改变正在写的草稿、不抢焦点。按住按键不会连续创建。
- 收下后小猫下方显示 **“已收下 · 点击撤销”**，6 秒内点击可撤销最近一次快捷收下；连续收下时撤销入口对应最后一条。开始编辑或改变完成状态后保留该记录。撤销只移除记录，不删除图片文件。
- 提示结束自动恢复待办数字。失败会提示，点击可查看原因；快捷键被占用时不会替换其他程序的注册，请退出占用它的原版或其他实例后重启。

预览采用奶油白与暖橙配色、矢量小猫、圆角卡片、阴影、按钮悬停反馈、面板淡入与位移动画、保存后小猫轻跳。动画仅在操作时播放，没有常驻动画循环。

文件附件保存在该目录的 files 子目录，图片在 images 子目录。

数据独立保存在 `%LOCALAPPDATA%\PocketPetSlintPreview`，不会读取或替换原生版数据。文字停顿 600 毫秒后保存草稿，图片保存在 images 子目录。

这是美化试验版：已接入全局快捷收下与撤销，尚未迁移快捷打开输入框、手动缩放等功能。已支持轻提醒与拖放收下。支持 Windows 系统 DPI 缩放。资源占用需以实际运行测量为准。全局快捷键使用阻塞消息循环，空闲时不轮询剪贴板。

## 轻提醒

展开已收下的记录后，点击“设置提醒”按需显示时间选项；顶部输入区默认直接记录，不要求设置时间：

- **30 分钟后**：从选择时起计算，选择后显示具体时间。
- **今天晚点**：当地时间今晚 21:00；已到/超过 21:00 时按钮改为“明早 9 点”。
- **不提醒**：取消该记录的提醒。旧草稿若已设置提醒，输入区会保留取消入口。

到点后小猫下方显示“有 N 条提醒 · 查看”，点击打开列表，到期事项排在前面。不会抢焦点、自动展开面板或播放声音；正在显示快捷收下/撤销提示时，提醒数量在该提示结束后显示。

- **30 分钟后**：推迟该事项的提醒。
- **知道了**：取消提醒，事项仍然未完成。
- **完成事项**：同时取消提醒；恢复未完成不会恢复旧提醒。

提醒时间保存在 state.json。退出期间不会触发；下次启动会显示已过期且未处理的提醒。草稿的提醒只有收下成为记录后才触发。没有未来提醒时不运行提醒定时器；有未来提醒时最长每 30 秒校对一次时间，以处理休眠恢复和系统时钟变化。

## 拖放收下

把内容拖到小猫身上：高亮并显示“松手，放进口袋”，松手后保存为新记录；移出或取消不保存。成功后同样有 6 秒撤销入口。

- **所选文字/链接**：接收来源程序提供的 Unicode 文本，不读取剪贴板。
- **图片**：支持本地图片文件，以及来源程序提供的 PNG / DIB 位图，保存副本并显示缩略图。
- **普通本地文件**：复制到独立的 files 目录；同一次拖入的多个文件合成一条记录。展开该记录后点“文件”可打开附件所在文件夹。
- 原文件不会移动或删除；拖放只向来源程序声明复制。撤销保留附件副本，避免破坏备份引用。
- 文件复制和导入在后台进行，显示“正在收下…”，不抢焦点、不替换当前草稿；导入期间暂不接受下一批拖放，也不通过应用退出按钮中断复制。

每次最多 32 个文件、合计 100 MB；暂不接收文件夹或邮件附件等虚拟文件。浏览器若只提供图片链接，会保存链接，不自动下载网络图片。不同来源程序能否提供文字/位图，取决于它的拖放格式。图片解码设有内存与尺寸上限。

## 开发

```powershell
cargo build --release --manifest-path slint-preview/Cargo.toml
cargo test --release --manifest-path slint-preview/Cargo.toml
```

从项目根目录运行测试前，请退出占用 Ctrl+Alt+V 的程序。使用 `--snapshot` 启动可导出真实 Slint 渲染的记录、宠物和待办截图至 `slint-preview/preview-output`，并在该独立目录验证自动聚焦、Enter/Shift+Enter、Esc 和草稿保存，结果写入 input-check.txt，并导出拖入高亮截图、检查原生拖放目标注册，再运行真实定时器、到期徽标、稍后提醒和知晓持久化检查，写入 reminder-check.txt 后自动退出。

PixPin 截图粘贴：图片库转换失败时会依次尝试 Windows DIBV5 / DIB，真实读取失败会显示提示。可用 `--snapshot --clipboard-check` 在隔离预览数据中验证当前剪贴板图片的 Ctrl+V 接收与持久化；该检查只读取剪贴板。

## 完成反馈与安静提醒

- 点击完成先保存状态，再播放约 1.1 秒的真实像素分层消散，随后平滑补位；其他记录仍可操作。最后一条完成时，小猫会做稍明显的舒展反馈。
- 底部“撤销完成”保留 6 秒，只撤销最近一次完成，并恢复原提醒。过期后可从“已完成”恢复；动画不删除记录或附件。
- 有待办且一小时没有查看口袋时，小猫轻轻抬起并显示提示，7 秒后收回；未查看则间隔延长到 2 小时、4 小时。查看后重新计时，重启也重新计时。
- 没有待办、面板正在显示、正在拖放或已有操作提示时，不插入周期提醒。定时提醒到点仍优先显示。不会自动展开面板、抢焦点或播放声音。
- 平时每 30 秒检查一次提醒条件；颗粒仅在完成动画期间创建，不在空闲时循环绘制。
- `--snapshot` 还会输出 `completion-dust.png`、`completion-collapse.png`、`attention-pet.png`，并通过 `completion-check.txt` 记录实际定时完成和撤销检查。小时级提醒间隔由模拟单调时间的单元测试验证。
### 像素分层消散（Snappable 思路）

完成时截取这张卡片在列表中实际可见的区域，排除滚动条与其他动画，将文字、图标和图片的像素分到 16 个透明图层，错时漂移和淡出；浅色底面单独淡出。只借鉴实现思路，仍使用 Rust / Slint，不引入 Flutter 或 WebView。

单张图像最多处理 120,000 像素，图层与底面的原始 RGBA 数据上限约 7.8 MiB（不代表整个进程内存），最多同时保留三组动画；超过时仍完成记录并以轻量收起处理。无需 PNG 编码，动画结束或撤销即释放图像。`snap-metrics.txt` 记录预览的截取与分层耗时、图层数和原始缓冲字节数；`completion-check.txt` 验证真实图层生成和缓冲释放。
卡片右下角显示相对加入时间，展开后显示本地准确时间。编辑和完成不改变加入时间；旧记录没有时间数据时仅在展开后标明未记录。面板展开时每分钟刷新，收起即停止。

气泡固定为 448 × 570 逻辑像素，空列表、完成最后一条、重新打开和图片预览均保持同一尺寸；待办超出空间时在内部滚动，清空后显示完成提示。

## 侧边待办栏（试用）

- 小猫旁显示独立悬浮气泡：当前条居中，上下各一条略小、略淡，没有外层底板和常驻工具栏。鼠标在气泡上滚轮翻阅。
- 新记录插在当前条下方，已有记录相对顺序不变；第一条自动居中。本版浏览顺序和左右偏好仅保留至退出。
- 悬停当前气泡，通过“···”菜单切换左右侧，屏幕边缘空间不足时自动选择放得下的一侧；拖动小猫时侧栏跟随。
- 悬停当前条后点击圆圈完成，复用像素消散并让下一条补位；独立的小提示可在 6 秒内撤销。点击正文打开原气泡详情，保留输入草稿。
- 打开完整面板时暂停悬停速览；关闭后保持收起，鼠标离开小猫再移入才重新触发。侧栏加入时间每分钟刷新；隐藏时停止刷新，没有常驻动画循环。
- `--snapshot` 输出 `side-rail.png`、`side-rail-dust.png` 和 `side-rail-check.txt`，检查滚轮事件、完成点击、像素图层、缓冲释放、撤销和详情草稿保持。
透明空隙由 Windows 窗口区域排除，不拦截后方窗口的点击；没有待办时不显示气泡，最后一条完成后短暂显示“都处理好了”。

悬停小猫 200 毫秒显示侧边滚筒；移向气泡或经过透明间隙时保留 400 毫秒宽限，离开小猫及气泡后收起。速览不激活窗口，不抢走其他软件的键盘焦点；拖动小猫时暂时关闭速览。

悬停诊断：`--trace-hover` 只记录进入/离开、计时器、面板及原生窗口显隐状态，不记录待办文字或图片；日志为数据目录下的 `hover-diagnostic.log`，上限约 512 KiB。默认不开启。Windows 悬停统一使用 CursorEntered / CursorMoved / CursorLeft，避免相同坐标再次进入被移动事件去重遗漏。

`--snapshot --native-hover` 会在隔离数据上实际移动鼠标，验证十轮相同位置的进入/离开；期间请勿操作鼠标，结束时自动恢复原位置。`hover-preview-check.txt`、`hover-cycles-check.txt` 和 `hover-quick-check.txt` 分别记录面板切换、十轮循环、快速掠过及拖动抑制结果。
