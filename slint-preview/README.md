# 口袋 · Slint 美化预览

独立的 Rust + Slint 桌面预览，使用 winit 窗口后端和软件渲染，无 WebView。

## 运行

双击 `target/release/pocket-pet-slint.exe`。首次打开会展示记录面板。

- 单击小猫：打开随手记；拖动小猫：移动位置。
- 点击待办徽标：查看卡片；点击圆圈完成，点击正文编辑。
- 输入气泡自动聚焦，Ctrl+V 在光标位置粘贴文字，粘贴截图显示附件预览。
- Enter 或“收下”保存；Shift+Enter 换行。输入法组词期间不拦截这些按键。
- Esc、× 或切换到其他窗口时收起并保留草稿；底部“退出”关闭程序。
- 空草稿保持紧凑，输入文字或粘贴图片后展开。
- **Ctrl+Alt+V**：全局快捷收下剪贴板，图片优先，其次文字/链接；不展开输入框、不改变正在写的草稿、不抢焦点。按住按键不会连续创建。
- 收下后小猫下方显示 **“已收下 · 点击撤销”**，6 秒内点击可撤销最近一次快捷收下；连续收下时撤销入口对应最后一条。开始编辑或改变完成状态后保留该记录。撤销只移除记录，不删除图片文件。
- 提示结束自动恢复待办数字。失败会提示，点击可查看原因；快捷键被占用时不会替换其他程序的注册，请退出占用它的原版或其他实例后重启。

预览采用奶油白与暖橙配色、矢量小猫、圆角卡片、阴影、按钮悬停反馈、面板淡入与位移动画、保存后小猫轻跳。动画仅在操作时播放，没有常驻动画循环。

数据独立保存在 `%LOCALAPPDATA%\PocketPetSlintPreview`，不会读取或替换原生版数据。文字停顿 600 毫秒后保存草稿，图片保存在 images 子目录。

这是美化试验版：已接入全局快捷收下与撤销，尚未迁移快捷打开输入框、手动缩放、原图查看等功能。已支持轻提醒，拖放尚未实现。支持 Windows 系统 DPI 缩放。资源占用需以实际运行测量为准。全局快捷键使用阻塞消息循环，空闲时不轮询剪贴板。

## 轻提醒

输入框下方的“不提醒 ▾”是可选入口，默认直接记录，不要求设置时间：

- **30 分钟后**：从选择时起计算，选择后显示具体时间。
- **今天晚点**：当地时间今晚 21:00；已到/超过 21:00 时按钮改为“明早 9 点”。
- **不提醒**：取消当前草稿或编辑记录的提醒。

到点后小猫下方显示“有 N 条提醒 · 查看”，点击打开列表，到期事项排在前面。不会抢焦点、自动展开面板或播放声音；正在显示快捷收下/撤销提示时，提醒数量在该提示结束后显示。

- **30 分钟后**：推迟该事项的提醒。
- **知道了**：取消提醒，事项仍然未完成。
- **完成事项**：同时取消提醒；恢复未完成不会恢复旧提醒。

提醒时间保存在 state.json。退出期间不会触发；下次启动会显示已过期且未处理的提醒。草稿的提醒只有收下成为记录后才触发。没有未来提醒时不运行提醒定时器；有未来提醒时最长每 30 秒校对一次时间，以处理休眠恢复和系统时钟变化。

## 开发

```powershell
cargo build --release --manifest-path slint-preview/Cargo.toml
cargo test --release --manifest-path slint-preview/Cargo.toml
```

从项目根目录运行测试前，请退出占用 Ctrl+Alt+V 的程序。使用 `--snapshot` 启动可导出真实 Slint 渲染的记录、宠物和待办截图至 `slint-preview/preview-output`，并在该独立目录验证自动聚焦、Enter/Shift+Enter、Esc 和草稿保存，结果写入 input-check.txt，并运行真实定时器、到期徽标、稍后提醒和知晓持久化检查，写入 reminder-check.txt 后自动退出。
