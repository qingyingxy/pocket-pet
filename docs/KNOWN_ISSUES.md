# 已知问题与验证边界

当前为 Windows Alpha 原型。以下问题不因编译、单元测试或快照通过而自动视为解决。

## 点击后顶部被覆盖：已复现并修复

实际使用中曾出现“Slint Window”标题栏、白底或局部显示异常。此前撤回小猫原生裁剪、强制分层及边框校正，由 Slint 管理窗口属性；2026-09-15 维护者反馈标题栏正常，暂未复现。

2026-10-06 根据实际误点反馈，将小猫图片默认缩小 25%，加入按图片透明度生成的精确窗口区域，排除透明空白和隐藏提示条，并同步动画、DPI 与悬停边界。窗口样式继续由 Slint 管理；区域扩展时整窗重绘。新增原生区域/窗口命中检查，多屏及长时间运行仍需持续观察。

同日用户反馈点击小猫后耳朵和数字上部被白色覆盖。已用失焦和非客户区重绘消息复现：winit 保留的标题栏样式会让 Windows 在异形窗口上绘制系统标题栏。小猫现在通过窗口子类阻止非客户区绘制，激活消息仍交给 winit；不修改窗口样式。每次实际重绘小猫时重新绘制完整表面，覆盖移动和隐藏恢复时失效的原生像素，不增加空闲轮询。

边界回归扩展到 15 种姿态、控件与窗口状态，加入两侧猫耳、数字字形、失焦/激活、边框重绘、隐藏恢复及点击展开/收起。证据同时包含原生桌面截图与 Slint 内部快照；此前仅采样脸和身体，未覆盖这次顶部问题。

侧边窗口重新展开曾只显示按钮小块，目前对展开帧标记整窗重绘。重复悬停检查通过，但仍需持续观察实际像素显示。

反馈时请附 Windows 版本、显示缩放比例、显示器数量、启动命令、复现步骤和脱敏截图。可用 `--trace-hover` 收集悬停状态日志；它不记录待办内容，但无法证明窗口最终画面正确。

## 使用限制

- 仅支持 Windows，尚未验证 Linux/macOS。
- Slint 版已加入单实例唤回；同时运行早期 Win32 原型仍可能发生快捷键冲突。
- 侧栏左右偏好已持久化；浏览顺序仍仅保留到退出。
- Slint 版尚未迁移原生版的手动缩放和 Ctrl+Alt+N。
- 退出程序期间不会发送提醒，下次启动才显示过期事项。隐藏小猫期间也不显示桌面提示，暂未接入系统通知。
- 拖入文件夹、虚拟附件暂不支持；浏览器图片拖入行为取决于来源提供的格式。
- 撤销不会立即删除附件副本，长期使用可能需要后续存储清理机制。

中文输入法、PixPin/其他截图工具、多屏不同 DPI、显示器边缘定位、睡眠恢复、焦点和鼠标穿透、长期空闲资源占用。自动测试不覆盖所有真实桌面操作路径。
