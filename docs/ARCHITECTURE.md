# 项目结构

当前保留两个独立二进制项目，未设置 Cargo workspace。根目录 Cargo 命令针对 Win32 原型；Slint 命令显式传入 `--manifest-path slint-preview/Cargo.toml`。

```text
note/
├── Cargo.toml / Cargo.lock      原生版依赖
├── src/
│   ├── main.rs                  原生版入口
│   └── ui.rs                    Win32 窗口、绘制与业务交互
├── slint-preview/
│   ├── Cargo.toml / Cargo.lock  Slint 版依赖
│   ├── build.rs                编译 Slint UI
│   ├── src/
│   │   ├── main.rs              窗口定位、UI 同步与回调
│   │   ├── store.rs             记录、草稿、撤销、缩略图与存储回归测试
│   │   ├── storage.rs           原子 JSON 保存、有效备份与损坏恢复
│   │   ├── attachments.rs       应用附件边界、引用保护与子目录清理
│   │   ├── diagnostics.rs       隔离诊断输出目录和参数
│   │   ├── benchmark.rs         模拟数据的性能测量入口
│   │   ├── hotkey.rs            全局快捷键注册与消息线程
│   │   ├── reminders.rs         时间预设、到期判断与调度间隔
│   │   ├── drop_target.rs       Windows OLE 拖放目标与数据解析
│   │   └── drop_import.rs       后台文件复制与图片导入
│   └── ui/
│       ├── app.slint            小猫窗口、输入气泡、待办卡片
│       └── cat.svg              矢量小猫
└── docs/                       原生版说明、路线与结构说明
```

## Slint 运行方式

使用 winit 窗口后端与软件渲染器。小猫、完整面板和侧边速览是三个声明为无边框透明置顶的窗口；面板按显示器工作区定位。交互使用短动画和单次定时器。

普通输入通过 Slint 回调修改编辑缓冲，停顿 600 毫秒后保存。全局快捷键线程阻塞等待 Windows 消息，将收下请求投递到 Slint 主事件循环；读取剪贴板、保存和更新 UI 都由主线程执行。

`Store` 保存记录、草稿、当前编辑目标、缩略图缓存和一次性撤销状态。撤销检查截止时间、记录内容及编辑状态，并在写盘成功后结束撤销。

## 数据文件

Slint 数据目录为 `%LOCALAPPDATA%\PocketPetSlintPreview`：

- `state.json`：记录和草稿；可选 `remind_at` 为 Unix 秒数，旧数据缺省为不提醒。
- `state.backup.json`：上一次写入前的状态。
- `state.tmp` / `state.backup.tmp`：完整写入并同步后替换正式文件；只把有效旧状态轮换到备份。
- `state.corrupt.*.json`：从有效备份恢复时保留的损坏原文件，不自动删除。
- `images/`：剪贴板/拖放图片。
- `files/`：普通拖放附件；记录中可选 files 数组保存显示名与相对路径。移除引用或撤销不删除附件，保留备份引用有效性。

`--snapshot` 改用 `slint-preview/preview-output/`，使用示例数据生成真实渲染截图和输入事件检查结果。该目录不进入 Git。

记录与草稿操作已提取到 store.rs，通用持久化在 storage.rs。启动时主数据缺失/损坏可恢复有效备份；两者均不可用则报错保留原件，不以空数据覆盖。权限和其他读写错误同样不会静默重置。flush 保存失败时恢复已提交状态，并保留可重试的输入缓冲；编辑记录和撤销完成同步更新编辑缓冲。

UI 重建列表时以附件相对路径复用当前模型已有的缩略图，避免超过 48 张图片后因缓存清空反复解码；独立缓存仍最多 48 项，当前可见模型持有的图片另计。速览顺序协调及按 ID 查找使用集合/映射，避免记录增多时出现二次遍历开销。

提醒只维护未来事项的单次定时器，回调更新徽标和列表后重新计算间隔；无未来事项则停止。到期状态由记录时间与完成状态推导，不另存易失的通知标记。

拖放关闭 winit 默认文件接收器，由小猫的 OLE IDropTarget 统一处理一批文字/位图/文件。悬停只检查格式，松手后读取载荷；文件导入在单个后台线程进行，结果投递回 Slint 主线程保存记录。退出时撤销拖放注册并平衡 OLE 初始化。

## 新增模块与窗口边界

- rail.rs：侧边记录顺序、定位、悬停计时器、Windows 侧栏区域裁剪和回归检查。
- pet_shape.rs：由小猫图片透明度生成原生窗口区域，合并可见徽标/提示/拖入背景；共用边界判断悬停。
- added_time.rs：加入时间显示。
- attention.rs：渐进退避的安静提醒策略。
- clipboard.rs：Windows 截图位图兼容处理。
- snap.rs：像素分层消散。

小猫默认图片尺寸为 96×96 逻辑像素，比之前缩小 25%；数字和提示条维持原字号。小猫窗口区域按图片的非透明像素和可见控件生成，透明空白不拦截其他应用的鼠标；隐藏控件不加入区域。区域会随 DPI、尺寸和姿态动画更新，静止时使用缓存，动画定时器在 280ms 后停止。区域坐标包含客户区与窗口原点的差值。窗口样式与透明输出仍由 Slint 管理。

侧边窗口使用区域裁剪排除卡片空隙。小猫区域扩展和侧栏重新展开时，共用整窗重绘函数，避免 Windows 裁剪/隐藏过的像素只恢复部分控件。小猫的实际 RedrawRequested 事件也标记整窗失效，但不请求下一帧，避免形成重绘循环。该函数使用锁定版本的 i-slint-core 内部接口，升级 Slint 时需一并检查接口和真实桌面显示。

winit 会保留 WS_CAPTION 样式位；只检查客户区原点和 is_decorated 不能证明系统不会绘制标题栏。小猫用 SetWindowSubclass 拦截 WM_NCPAINT，并以 lParam=-1 转发 WM_NCACTIVATE：保留框架的激活通知，抑制系统标题栏覆盖。WM_NCDESTROY 时移除子类，新 HWND 会重新安装并重建区域。窗口样式仍由 Slint 管理。

## 托盘管理

tray.rs 使用独立的阻塞 Win32 消息循环维护隐藏所有者窗口、通知区域图标和菜单；动作投递到 Slint 主线程后才访问 UI/Store。winit 的 skip_taskbar 和 owner_window 属性控制窗口收纳，不手工重写小猫的透明/边框样式。菜单重入时使用 Cell 存储可变状态，避免持有跨原生消息循环的独占引用。

正常启动先取得命名互斥对象；重复启动通过管理窗口投递唤回消息。测试预览跳过互斥，使用独立数据。主事件循环采用 run_event_loop_until_quit，全部窗口隐藏后仍可通过托盘恢复。退出时销毁图标和管理窗口，释放互斥句柄。

置顶、已完成列表展开状态和侧栏左右偏好写入独立 preferences.json，写入成功后更新对应的 Slint 属性；偏好文件也保存上一次有效备份，旧版缺省侧栏偏好为左侧。开机启动只操作当前用户的专用 Run 值，不需要管理员权限。启动时不自动注册。

## 删除与本地安装

deletion.rs 实现保存成功后才生效的删除与逆序批量恢复，10 秒撤销期从最后一次删除计算。数组索引变化时清除完成动画、旧撤销和侧栏顺序，避免旧回调作用到其他记录。附件清理检查当前数据、草稿和备份引用，使用规范路径保护不同分隔符指向的共享副本；attachments.rs 限制删除目标在数据目录的 images/files 内，拒绝路径穿越、符号链接和目录联接，支持拖入附件的批次子目录。只删除单个副本和随后为空的批次目录，不递归删除；备份保留的副本没有跨重启清理队列。

--snapshot --delete-check 使用隔离示例数据检查恢复、连续删除、撤销和真实到期，生成 deletion-check.txt、completed-actions.png 与 deletion-toast.png。单元测试覆盖写入失败回滚、顺序恢复、草稿保护与附件保留。

scripts/install.ps1 安装到当前用户目录并创建快捷方式；通过 --quit 请求托盘管理窗口正常保存退出，保存或导入阻止退出时中止覆盖。
