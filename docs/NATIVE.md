# 口袋宠物 · 快速记录版

Windows 原生 Rust/Win32 备忘工具，无 WebView、无后台剪贴板监听。

新增独立的 [Slint 美化预览版](../slint-preview/README.md)，用于体验矢量小猫、柔和卡片和过渡动画。

## 运行

退出旧版后运行 `target/zoom/release/pocket-pet.exe`。原来的卡片和草稿继续保留，多个版本不要同时运行。

- **单击小猫 / Ctrl+Alt+N**：直接打开输入框，光标就位。
- **Enter**：收下并关闭输入框；Shift+Enter 换行。中文输入法组合输入期间不截获 Enter。
- **Ctrl+V**：在输入框粘贴文字或截图。
- **Ctrl+Alt+V**：直接保存当前剪贴板，不展开编辑框；优先图片，其次文字/链接。空内容不建任务。
- 直接收下后，徽标短暂显示「已收下 · 待办 N · 撤销」。6 秒内点击可撤销最近一次收下；已编辑过的记录不会被撤销删除。重复按下会创建独立记录，但按住快捷键不连续触发。
- **待办徽标**：展开列表。成功提示期间先用于撤销，提示结束后恢复待办入口。
- **Esc / ×**：保存草稿并收起。
- 拖动小猫移动位置；根据移动距离区分点击与拖动。拖动时展开内容暂时收起，松手恢复。
- 右键小猫可退出。快捷键被占用会在启动时提示。

点击卡片正文编辑，停顿 600 毫秒自动保存；点击圆圈完成/恢复，已完成默认折叠。点击缩略图选择附件并用系统图片应用查看原图。输入区「移除」移除附件引用，不删除磁盘图片。

## 可调缩放

- 右键小猫 →「显示缩放」：选择 75%、100%、125%、150%、175%。
- 鼠标放在小猫、徽标或浮层上，按住 Ctrl 滚动：每格增减 10%，限制在 75%～175%。
- 「恢复默认大小」回到 125%。
- 小猫、窗口、字体和点击区域同步缩放；缩放时尽量保持小猫中心位置，靠屏幕边缘自动约束。
- 设置自动保存在 `%LOCALAPPDATA%\PocketPet\settings.json`，重启恢复，并叠加 Windows 自身的 DPI 缩放。

## 显示与资源

取消「＋记录」胶囊，只保留待办徽标。默认使用 125%：Windows 100% 缩放下，输入浮层约 425 像素宽，正文约 18 像素。启用每显示器 DPI 感知，跨屏时重算窗口、控件及编辑器字体。高缩放下，上下放不下时尝试在小猫左右放置浮层。

没有常驻动画。拖动跟随定时器松手后停止；成功/失败提示 6 秒后停止。只在用户主动操作时读取剪贴板，不修改剪贴板内容。缩略图缓存有数量上限。

## 数据

`%LOCALAPPDATA%\PocketPet`：`notes.json` 保存卡片，`notes.backup.json` 保存前一版本，`draft.json` 保存草稿，`images` 保存图片。撤销保留磁盘附件文件，避免破坏备份中的图片引用。强制结束程序可能丢失最后 600 毫秒输入。

## 构建与验证

以下命令从项目根目录运行。

```powershell
& "$env:USERPROFILE\.cargo\bin\cargo.exe" test --offline
& "$env:USERPROFILE\.cargo\bin\cargo.exe" build --release --offline --target-dir target\zoom
```

同一套 GDI 绘制程序的预览：

```powershell
& "$env:USERPROFILE\.cargo\bin\cargo.exe" test --offline render_surfaces_for_review -- --ignored
```

结果为 `target/capsule-preview.png`（非桌面截图）。测试覆盖 100%～200% 缩放下的浮层定位、负坐标副屏、备份/草稿隔离及撤销保护。完整桌面交互、实际跨 DPI 拖动和不同中文输入法仍需实机体验，尚无 CPU/内存实测。极小工作区可能容不下全部内容。
