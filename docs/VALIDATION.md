# 优化阶段验收

当前仍为 Windows Alpha。目标是让记录可靠保存、日常桌面操作稳定，并用可复现的数据决定性能优化。

## 一次运行自动验收

先从托盘退出 Pocket Pet，释放 Ctrl+Alt+V，在仓库根目录执行：

```powershell
./scripts/verify.ps1 -Offline
```

首次下载依赖时去掉 `-Offline`。脚本检查格式、运行测试、构建发布版，再依次运行输入/图片/完成/提醒/速览/悬停、删除、托盘、小猫边界四组检查。每组使用全新目录，结果位于 `slint-preview/preview-output/validation/<本次运行>/`，不会读取正式数据或修改开机启动。

脚本会拒绝缺失报告、FAIL、失败布尔项、非零退出和超时；进程退出成功本身不能使验收通过。`validation.json` 汇总检查项，各组的文本报告和 PNG 保留详细证据。`-SkipBuild` 仅用于确认当前发布 exe 已与源码一致时；默认应重新构建。

普通悬停检查使用框架输入事件与真实定时器。要额外用实际 Windows 鼠标移动检查十轮重入和快速掠过：

```powershell
./scripts/verify.ps1 -Offline -NativeHover
```

这项会短暂移动鼠标，运行期间不要操作鼠标；结束时恢复位置。它仍不能证明所有 DPI 下的最终显示像素正确。

原生循环检查还记录 Windows 实际命中的窗口类（不记录窗口标题或待办）。指针被移动、或其他窗口遮住小猫时，结果为 `INCONCLUSIVE`，脚本仍拒绝验收通过；应在桌面空闲时重新验证。

## 自动覆盖范围

| 领域 | 验证内容 |
| --- | --- |
| 保存与恢复 | 草稿/附件/提醒持久化，保存失败回滚，有效备份恢复，主数据与备份损坏时保留文件 |
| 完成与撤销 | 最后一次完成、过期/修改保护、编辑中的完成撤销再次保存仍有效、动画缓冲释放 |
| 删除 | 待办/已完成删除、连续删除逆序恢复、新增记录保留、保存失败、10 秒到期 |
| 附件边界 | 平铺和批次目录副本、共享路径别名、草稿与备份引用、路径穿越、目录联接、源文件保留 |
| 输入与界面 | 聚焦、Enter/Shift+Enter、Esc 草稿、列表重建与滚动复位、独立编辑、图片返回 |
| 桌面集成 | 快捷键消息/冲突/释放、OLE 格式解析与注册、悬停时序、托盘消息与窗口属性 |
| 小猫边界 | 100%–200% 五档轮廓测试；15 种姿态/控件/窗口状态的原生区域、透明点窗口命中、猫耳/身体/数字实际像素、激活/失焦与边框重绘、隐藏恢复、指针拖动/点击和面板展开/收起 |
| 偏好 | 置顶、已完成展开、侧栏左右偏好、旧字段兼容、损坏设置恢复且不改记录 |

## 仍需真实使用确认

记录实际 Windows 版本、显示缩放和显示器数量后逐项检查，发现问题时保留复现步骤及脱敏截图：

- 单屏 100%/125%/150%/175%/200%，以及两台显示器采用不同缩放时，拖动、跨屏、屏幕边缘展开、拔掉外接显示器后找回小猫。
- 微软拼音及实际常用输入法：组词期间 Enter 只确认候选；确认后 Enter 收下；Shift+Enter 换行；切换其他应用时保留草稿。
- PixPin 和其他实际截图工具的 Ctrl+V；资源管理器、多种编辑器和浏览器的真实拖入；核对附件副本及原件。
- 托盘菜单、任务栏、Alt+Tab、透明间隙点击后方窗口；Explorer 重启后托盘恢复。
- 睡眠/唤醒、跨午夜、时区或系统时间变化后的到期提醒；隐藏期间安静，恢复后可见到期事项。
- 连续使用至少一天：无残留窗口、提示或动画；草稿及侧栏偏好重启后正确；记录和附件能打开。
- 本地安装/更新：用 `scripts/install.ps1 -WhatIf` 先检查目标，再进行实际安装；旧实例保存退出、原有数据保留、快捷方式及已开启的开机启动路径正确。

测试和诊断输出不上传 GitHub，也不要用真实待办作为共享截图。以上未完成项目应保持“待验证”，不能由单元测试或快照通过替代。

## 本轮修复

- 增加有效备份恢复和损坏原件保留；显示偏好可恢复，记录不能静默重置。
- 修复编辑缓冲与撤销完成不一致，以及草稿保存失败时内存状态提前提交。
- 修复批次附件未清理，统一附件边界与共享引用保护。
- 保存侧栏左右选择；旧版仍默认左侧，屏幕边缘继续自动避让。
- 降低侧栏协调的重复遍历，复用已有缩略图；增加隔离的性能测量和严格报告验收。

本轮的测试、实测结果和限制见 [性能测量](PERFORMANCE.md) 及 [已知问题](KNOWN_ISSUES.md)。
